# Release notes

## 7.1.1 — First public preview

- Public documentation and feedback forms in English, Spanish, French, Simplified Chinese, German and Brazilian Portuguese.
- Personal project statement: Spanish-speaking creator, not a programmer, built with AI assistance to better understand and care for a MacBook; bugs and imperfect translations are expected possibilities.
- Current support scope explicitly limited to MacBook Air and Pro M1–M5. Neo is no longer marked supported; only one Air M5 has been physically tested.
- Full-charge daily-routine estimate from observed seven-day history; honest learning progress, ranges and confidence, with no manual activity/duration selection on the home screen.
- Eight companion states; brief animations when shown or when mood changes, with background/accessibility/power pauses.
- Automatic sessions, battery history, daily apps, familiar-place maps, manual location and return-home advice retained.
- Black/green interface, English initial language and five switchable alternatives retained.
- Source, test and build scripts included. Local ad-hoc signature only; Developer ID signing, notarization and wider physical validation remain pending.

This is a preview, not a claim of production readiness, measured lifespan improvement or validated battery savings across all models.
