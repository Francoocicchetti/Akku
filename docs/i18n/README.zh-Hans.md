# Akku

**从你的日常习惯，了解电池续航。** 为 M1–M5 MacBook Air 和 MacBook Pro 制作的实验性原生 macOS 伙伴应用。

## 为什么制作 Akku

我的母语是西班牙语，我也不是程序员。我借助 AI 工具制作 Akku，是因为想更好地照顾自己的 MacBook，了解它的电池：按我的习惯能用多久，通常在哪里充电，什么时候应该带充电器。

这个项目最初是为了自己 MacBook 的健康而做的。我希望应用主动了解日常使用，而不是让我逐项填写正在做什么。Akku 也是陪伴用户的小猴子：精力充沛、困倦、想吃电，或者安静地提醒你休息一下。

**这是个人实验项目，可能存在故障、不准确的估算以及尚不完善的行为。** 我不声称自己是专业开发者，也没有测试过所有 MacBook。公开它，是希望大家试用、查看代码并帮助改进。它不会修复电池，也没有证据证明它一定能延长电池寿命。

因为我主要说西班牙语，**部分翻译可能不自然或有错误**，包括这份说明。如果发现问题，欢迎纠正。你可以使用全部六种支持语言中的任意一种提交反馈。

## 兼容范围与语言

当前版本**仅面向搭载 M1、M2、M3、M4 或 M5 的 MacBook Air 和 MacBook Pro**，包括相应的 Pro/Max 芯片版本。目前实机测试仅在**一台 MacBook Air M5** 上完成；识别机型并不代表已经验证所有配置。

要求 macOS 13 或更新版本，同时须满足该 Mac 本身的最低系统要求。较早的兼容 macOS 版本仍需实机验证。Intel Mac、台式 Mac、MacBook Neo、Windows 和 Linux 不在当前支持范围内。构建脚本能生成 Intel 架构部分，也不代表承诺支持 Intel。

全新安装默认使用英语。可从顶部菜单或设置切换到西班牙语、法语、简体中文、德语或巴西葡萄牙语，选择会保存。

## 应用功能

### 充满电，按你的日常习惯

Akku 根据**最近七天观察到的实际使用组合，估算电量从 100% 到 0% 可使用多久**。主界面不需要选择活动，也不需要手动输入时长。

计算依据是实际电量百分比下降量与电池供电时观察到的 Mac 唤醒时间。充电、睡眠和缺失的观测区间不计入。此项估算不扣除安全余量，也不会把当前电量当作满电。

首次显示估算需要三个有记录的日期，每天至少十分钟，总计至少九十分钟，并观察到五个电量百分点的消耗。在此之前，应用显示学习进度，不编造个人续航。结果以范围和置信度呈现；日与日之间差异越大，范围越宽。在缺少真实长期校准时，日常续航置信度最高为中等。新的工作负载、配件或使用条件可能改变结果。

### 自动记录与历史

断开充电器会自动开始记录。如果打开 Akku 时已经使用电池，则从打开时开始观察。确认离开家也可触发记录，不需要点击扫描或开始。充电器仍连接、但优化充电暂停时，不会误判为拔掉电源。

睡眠和记录中断不计入；唤醒后继续观察。电源连续连接一分钟后结束该次记录。Akku 必须保持运行才能学习；开机登录时启动是可选项。关闭学习会暂停记录。

统计包括一周使用、记录次数、消耗的电量百分点，以及在家、外出和位置未知的时间。电池面板提供**最近 24 小时和 10 天**的电量、充电/接电时段、观察到的亮屏时间和区间详情。没有数据的历史会保持空缺。亮屏不代表人一直在操作；多次充电后，累计消耗可超过 100 个百分点。

### 真实应用与组合

Akku 通过 macOS 原生信息识别 Safari、FaceTime、ChatGPT、WhatsApp 等已打开应用，并显示图标。打开时长与前台使用时长分开统计，也可按日期和地点查看。

它还能观察某些应用组合打开时整台 Mac 的耗电情况。**CPU 使用率不是每个应用的精确能耗。** FaceTime 打开不代表正在通话；Safari 内的网站仍显示为 Safari。应用不会读取消息、文档、浏览器标签内容、屏幕内容或按键。后台通话和没有操作的阅读可能被低估。

### 地点、地图与回家建议

Apple MapKit 交互地图展示常去地点、观察到的充电、低电量事件，以及 7 天或 30 天的使用情况。选中地点可查看相关应用和电池记录。多次访问后可建议“家”或“工作地点”，但由你确认地点的含义。

自动定位需要 macOS 授权，也可以关闭；没有定位，电池学习仍然可用。你可以手动输入地点或当前位置。手动当前位置有效三十分钟，不会被当作自动检测到的离家。地址搜索仅在点击“搜索”时查询 Apple Maps。

确认位置变化后，Akku 可以轻声提示“出门了吗？”，但并非实时或绝对准确。到家的距离是**直线距离，不是道路路线或预计行程时间**。现在充电还是回家再充的建议，会结合电量、安全余量和你提供的回家/使用时长；它不能保证回家前电量一定足够。Akku 不是“查找”，不能远程定位已关机的电脑。

### 有动画的小伙伴

Akku 有八种状态：准备好、精力充沛、正在充电、电量低、快没电、休息时间、夜晚和外出。“喂 Akku”就是连接真正的充电器。提示依据时间、电量、近期使用和获准的位置信息，不需要远程 AI 服务，也不是无所不知。

角色在显示或状态变化时播放动画，之后间歇短暂活动。界面隐藏、低电量模式、紧急模式或减弱动态效果开启时会暂停。休息提醒仅在应用内显示，可静音；它是粗略提醒，不是健康监测。

### 紧急模式与自身耗电

紧急模式尝试降低兼容屏幕的亮度，减少 Akku 自身的查询，展示已应用的操作，并提供撤销。低电量模式和其他应用的同步仍需手动管理。关闭其他应用需要确认，采用正常退出而非强制结束；可能中断通话或上传。重新打开不会恢复未保存内容，也不保证额外一小时续航。

后台通常每分钟观察一次，界面可见时约每三十秒一次；睡眠会停止定时器。写入合并处理，CPU 检查按需执行，定位失败后逐渐减少重试，动画以每秒八帧的短序列播放。**低耗电是设计目标，不代表零耗电，也不是所有机型都已验证的结论。**

## 隐私

无需 Akku 账户，没有开发者运营的分析平台或服务器。历史保存在 `~/Library/Application Support/BatteryTrip`，保留旧名称是为了兼容原有数据。记录包括电池、应用标识与使用、地点坐标及汇总访问，而非连续移动轨迹。地图、地址搜索和 macOS 定位服务可能与 Apple 通信。

可在设置中删除学习数据，在地点中删除位置信息。导出包含电池观测和应用标识，但不含坐标或地点关联。**公开分享前请检查并遮盖个人信息。** 不要在问题报告中上传家庭地址、位置截图或个人使用记录文件。

## 安装与编译

从 [Releases](https://github.com/Francoocicchetti/Akku/releases) 下载 ZIP，解压后把 `Akku.app` 移至“应用程序”。替换前退出旧版本，偏好与历史会保留。关闭窗口后菜单栏应用仍运行，请勿同时启动两个版本。

预览版只有**本地 ad-hoc 签名，没有 Apple Developer ID 签名或公证**。macOS 可能警告或拒绝打开。本项目不要求关闭系统安全机制；面向更广泛分发的签名仍待完成。

编译需要 Mac、Python 3、Xcode/Command Line Tools、兼容的 macOS SDK 及 Swift 5.9 或以上，无需第三方软件包：

```sh
./test.sh
./build.sh "$PWD/dist"
```

`notarize.sh` 需要维护者自己的 Developer ID 证书和钥匙串公证配置，本仓库不包含凭据。
